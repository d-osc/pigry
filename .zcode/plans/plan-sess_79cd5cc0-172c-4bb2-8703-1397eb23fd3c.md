# Terminal แบบ VS Code 100% — PTY จริง + xterm.js

## Context

Terminal ปัจจุบันใน pigry เป็น "fake terminal" (`src/app/TerminalPanel.tsx`): input box + รายการบรรทัด รันคำสั่งทีละคำสั่งผ่าน `terminal_run` (busybox built-ins + cmd /C fallback) — ไม่มี PTY จริง จึงไม่มีสี ANSI, interactive programs (python REPL, vim, `git rebase -i`, npm prompts), autocomplete ของ shell เอง หรือ cursor movement ทำงาน ผู้ใช้ต้องการ terminal เหมือน VS Code: ทางออกคือ **ConPTY ฝั่ง backend (portable-pty) + xterm.js ฝั่ง frontend** ซึ่งเป็นสถาปัตยกรรมเดียวกับ VS Code เองใช้

ข้อจำกัดที่ต้องเคารพ (จากการสำรวจ):
- `terminal_run` + busybox modules **ต้องเก็บไว้** — agent tools (`run_command` ใน agentTools.ts) และ hooks (`runEventHooks` ใน agentExtras.ts:832) ยังใช้อยู่ แค่หยุดใช้จาก TerminalPanel
- Contract ที่ต้องคง: `pigry:toggle-terminal` CustomEvent (AppShell listener + AppSettingsScreen ghLogin), TerminalPanel ปิด panel เมื่อ tab สุดท้ายถูก kill (EditorPane ส่ง `onClose={() => onToggleTerminal?.()}`), ResizeHandle API (`orientation: 'v'|'h'`, `onDelta`)
- Rust patterns ที่จะเลียนแบบ: watcher.rs (std::thread + `app.emit`), browser.rs (`static LazyLock<Mutex<HashMap>>` state), gh.rs (probe known paths หา binary), lib.rs:13 `CREATE_NO_WINDOW` trait
- ไม่มี RunEvent cleanup ใน lib.rs (เพิ่งจะมีครั้งแรก) — `app.run(|_,_| {})` อยู่บรรทัด 299

## Backend — `src-tauri/src/pty.rs` (ไฟล์ใหม่)

Dep เพิ่ม: `portable-pty = "0.8"` (wezterm's crate, ConPTY บน Windows, ไม่พ่วง TLS/ring — ปลอดภัยกับ toolchain arm64 bat) ถ้า compile ไม่ผ่านบน aarch64 ใช้ fallback `conpty` crate (Windows-only)

- **State**: `static PTYS: LazyLock<Mutex<HashMap<u32, PtySession>>>` (ตามแบบ browser.rs:17) — PtySession { master, writer, child } + `AtomicU32` id counter
- **Commands** (register ใน generate_handler! lib.rs:136–295):
  - `pty_create(shell_id, cwd, app: AppHandle) -> { id, label, shellName }` — openpty 80×24, spawn shell, spawn reader thread (แบบ watcher.rs) อ่านจาก `try_clone_reader()` → emit `"pty://output" { id, data }`; buffer เศษ UTF-8 ข้าม chunk (valid_up_to) กันตัวอักษรไทย/emoji แตก; EOF → emit `"pty://exit" { id, exitCode }`
  - `pty_write(id, data)` / `pty_resize(id, cols, rows)` / `pty_kill(id)` (child.kill + remove session)
  - `pty_list_shells() -> ShellProfile[]` — probe แบบ gh.rs: PowerShell (System32, default, `-NoLogo`), CMD, pwsh (PATH + Program Files), Git Bash (Program Files + LOCALAPPDATA + C:\msys64), WSL (ถ้ามี wsl.exe)
- **Cleanup ตอนปิดแอป**: เปลี่ยน `app.run(|_,_| {})` เป็น match `RunEvent::Exit` → kill ทุก child (kill-all helper ใน pty.rs)
- Inline tests (แบบ watcher.rs): UTF-8 chunk splitting helper, shell profile detection shape

## Frontend

npm deps: `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-web-links`, `@xterm/addon-search`

1. **`src/lib/tauriClient.ts`** — wrappers `ptyCreate/ptyWrite/ptyResize/ptyKill/ptyListShells` (isTauri guard + demo fallback ตาม pattern readWorktreeFile) + types `ShellProfile`, `PtySessionInfo`, `PtyOutputEvent`
2. **`src/app/PtyTerminalView.tsx`** (ใหม่) — xterm instance ต่อ session: theme จาก CSS vars (`--bg-panel`/`--text-primary`/`--border`, อ่าน runtime เพื่อรองรับ light theme), JetBrains Mono (`--font-mono`), fontSize 12, scrollback 2000, cursor block+blink; `onData → ptyWrite`, `onTitleChange → tab label` (OSC title tracking แบบ VS Code), FitAddon + ResizeObserver → `pty_resize`; output listener filter ตาม id; exited → แถวแดง "process exited (code N)"
   - **คีย์ลัดแบบ VS Code Windows**: Ctrl+C = copy ถ้ามี selection ไม่งั้นส่ง ^C ไป shell; Ctrl+V = paste (native textarea paste), Ctrl+Shift+V = paste; Ctrl+Shift+C = copy; คลิกขวา = copy ถ้ามี selection ไม่งั้น paste (rightClickBehavior: copyPaste); Ctrl+F = find widget เล็ก (SearchAddon, findNext/findPrevious); web-links addon = ลิงก์คลิกได้
3. **`src/app/TerminalPanel.tsx`** — rewrite ทั้งไฟล์ เป็นโครงสร้าง VS Code:
   - Props เดิม (`cwd`, `onClose`) + `visible` ใหม่ — EditorPane render **ตลอด** (key=localPath) แล้วซ่อนด้วย CSS แทน unmount เพื่อให้ PTY + scrollback รอดตอนปิด/เปิด panel (แก้ `EditorPane.tsx:776`)
   - **Pane tree**: `PaneNode = leaf(terminalId) | split(dir, children[])` — ปุ่ม Split สร้าง terminal ใหม่คู่กับ pane ปัจจุบัน (divider ใช้ ResizeHandle เดิม), ปิด pane → collapse node
   - **Tabs row**: tab ต่อ terminal (label จาก shell/OSC title, icon, X บน hover), active highlight, ดับเบิลคลิก = rename inline; **▾ dropdown ข้าง +** = เลือก shell profile จาก `pty_list_shells` (จำตัวสุดท้ายที่ใช้)
   - **Actions ขวา** แบบ VS Code: split, kill active, maximize (toggle ความสูงเต็จ), close panel; context menu บน tab (Rename/Split/Kill) ใช้ `.context-menu` CSS เดิมจาก global.css
   - เอา autocomplete dropdown + COMMANDS array เดิมออก (shell เติมคำเองด้วย Tab แล้ว)
4. **`src/app/TerminalPanel.css`** — rewrite หน้าตา VS Code (tabs bar, actions, pane dividers, find widget) ใช้ tokens เดิมทั้งหมด
5. **`src/app/AppShell.tsx`** — เพิ่ม **Ctrl+`** toggle terminal ใน global keydown ที่มีอยู่ (L320–388) + **Ctrl+Shift+`** = terminal ใหม่ (dispatch `pigry:terminal-new`); เพิ่มบรรทัดอธิบายใน `ShortcutSheet.tsx`
