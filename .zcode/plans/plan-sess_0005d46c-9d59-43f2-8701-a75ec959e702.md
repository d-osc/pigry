## Context

ตามที่เลือกกัน: เพิ่ม **AI Agent แบบ split view** ใน floating Browser panel — แชตอยู่ rail ด้านขวาของเว็บ (webview หดซ้าย) ในโหมด **ย่อ (เฉพาะแชต)** คือไม่มี tab tools/mcp/agents/hooks/instructions โดย reuse `AiAgentPanel` เดิม ผ่าน prop ใหม่ `chatOnly` และ scope แชตเป็น team `'Browser'` (มีอยู่แล้วใน AGENT_TEAMS) เพื่อแยก sessions จากหน้าอื่น

ข้อจำกัดสำคัญ: native webview ซ้อนเหนือ HTML ทุกชั้น จึงต้อง**หด webview rect ด้วย `browserPosition`** ให้พื้นที่ rail เป็นของ HTML — ซึ่งเป็นกลไกเดิมของ BrowserPanel อยู่แล้ว (drag/fold ใช้เทคนิคเดียวกัน)

**ไม่มีการแก้ไข Rust/backend เลย** — ใช้ `browser_position` เดิมทั้งหมด

## การแก้ไข

### 1. `src/screens/explorer/AiAgentPanel.tsx` — เพิ่ม prop `chatOnly`
- เพิ่ม `chatOnly?: boolean` ใน `AiAgentPanelProps` (บรรทัด ~727) + destructure `chatOnly = false` (บรรทัด 751)
- Tab bar (บรรทัด 2223-2267): ซ่อนปุ่ม 7 tab เมื่อ chatOnly (`{!chatOnly && (tab list).map(...)}`) แต่**เก็บ**ปุ่ม project-memory/skills ไว้ท้าย nav (ยังเข้า dialog ได้)
- Tab panels (บรรทัด 2269-2275): ครอบ 6 tab panel ด้วย `!chatOnly &&` และเปลี่ยนเงื่อนไข block chat เป็น `{(chatOnly || panelTab === 'chat') && (...)}`
- ส่วนอื่น (header/session popover, message body, composer, model picker) ใช้เดิม — mount ทั้ง 4 จุดเดิมไม่กระทบ (prop เป็น optional, default false)

### 2. `src/app/BrowserPanel.tsx` — split layout + geometry
- Import: `AiAgentPanel` จาก `../screens/explorer/AiAgentPanel`, `ResizeHandle` จาก `./ResizeHandle`, `Sparkles` จาก lucide, `useRepository`
- State ใหม่ (persist ผ่าน localStorage ตามแบบของโปรเจกต์):
  - `agentOpen` (key `pigry:browser-agent`) — toggle ด้วยปุ่ม ✦ (Sparkles) ในแถว tabs-row controls วางก่อนปุ่ม Minus ใช้ class `browser-win__ctl` + สถานะ active
  - `railW` (key `pigry:browser-agent-w`, default 360, clamp 280–560)
- Geometry ใน sync effect (บรรทัด ~92-129): ความกว้าง webview rect เป็น `geom.w - (agentOpen ? railW : 0)` และเติม `agentOpen, railW` ใน dependency array — webview ถูก `browserPosition` ใหม่ทันทีที่ rail เปิด/ลาก divider (กลไก rAF-coalesce เดิม)
- Resize corner (บรรทัด 236): ค่า min width เป็น `MIN_W + (agentOpen ? railW : 0)`; เวลาเปิด rail ถ้า geom.w ไม่พอ ให้ขยาย geom.w ตาม (clamp ด้วย window.innerWidth - geom.x)
- Divider ระหว่างโซนเว็บกับ rail: reuse `<ResizeHandle orientation="v" onDelta={(dx) => setRailW(w => clamp(w - dx, 280, geom.w - 280))} ... />` (API `onDelta` ตาม src/app/ResizeHandle.tsx:4-10)
- JSX ใน `.browser-win__view` (บรรทัด 360-368): ครอบ note เดิมด้วย `<div className="browser-win__web">` เมื่อ agentOpen ต่อท้ายด้วย `<ResizeHandle>` + `<aside className="browser-win__agent">` ที่ mount:
  ```tsx
  <AiAgentPanel
    chatOnly
    width={railW}
    fileName={repository?.name ?? 'pigry'}
    defaultTeam="Browser"
    onCollapse={() => setAgentOpen(false)}   // ปุ่ม chevron ใน header ของ panel ก็ปิด rail ได้
  />
  ```
  (ไม่ส่ง `onOpenFile`/`selection` — เป็น optional props, tool chips จะไม่เปิดไฟล์ซึ่งเหมาะกับบริบท browser)

### 3. `src/app/BrowserPanel.css` — สไตล์ rail
- `.browser-win__view--split { display: flex; }` + `.browser-win__view--split .browser-win__web { flex: 1; min-width: 0; }`
- `.browser-win__agent { display: flex; flex-direction: column; min-width: 0; overflow: hidden; border-left: 1px solid <สีเส้นเดียวกับ panel>; background: <พื้นเดียวกับ .browser-win>; }`
- Override ตาม pattern ของ `src/screens/ai-agent/AiAgentScreen.css:688`: `.browser-win__agent .explorer-ai { flex: 1; min-height: 0; border-left: none; }` (ความกว้างมาจาก inline `width` prop อยู่แล้ว)
- สไตล์ `--active` ของปุ่ม ✦ และจูนสี ResizeHandle ในบริบท panel สีเข้ม (scoped ใน `.browser-win`)
