A FEW GOOD QUESTIONS

ก่อนเริ่ม
มีอะไรอยากรู้ไหม?

คุยกันต่อบน GitHub
ใช้กับ Git repository ที่มีอยู่ได้ไหม?+

ได้เลย เปิดโฟลเดอร์ repo บนเครื่องแล้วเริ่มทำงานต่อได้ Pigry ใช้ Git CLI สำหรับการทำ commit และทำงานกับ remote จึงใช้การตั้งค่า Git และ hooks ที่คุณมีอยู่ได้

ต้องสมัคร AI เพิ่มหรือเปล่า?+

คุณเลือกเชื่อมต่อ AI provider หรือ coding CLI ของตัวเองได้ การเข้าถึงโมเดลและค่าใช้จ่ายขึ้นอยู่กับบริการที่เลือก Pigry ไม่ได้รวมโควตา AI มากับตัวติดตั้ง

ข้อมูลของฉันอยู่ที่ไหน?+

Git repository อยู่บนเครื่องของคุณ ฟีเจอร์ GitHub และ AI จะเชื่อมกับบริการที่คุณเลือก และอาจส่งข้อมูลตามงานที่คุณสั่งให้บริการนั้นประมวลผล

ดาวน์โหลดเวอร์ชันไหนได้บ้าง?+

ดาวน์โหลด v0.3.0 สำหรับ Windows x64 ได้จากปุ่มด้านบน สำหรับ Windows ARM64, MSI และ Linux (.deb, .rpm, .AppImage) ทั้ง x64 และ ARM64 เลือกแพ็กเกจจาก Release บน GitHub ได้ ตัวติดตั้ง Windows ยังไม่ได้เซ็นดิจิทัล
