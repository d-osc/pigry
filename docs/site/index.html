A FEW GOOD QUESTIONS

A little more
before you begin.

Keep the conversation going on GitHub
Can I open a repository I already have?+

Absolutely. Open a local Git repository and pick up where you left off. Pigry uses the Git CLI for commits and remote operations, so your existing Git configuration and hooks can come along.

Is an AI subscription included?+

You connect your own AI provider or coding CLI. Model access and any usage costs depend on the service you choose. The installer does not include an AI usage allowance.

Where does my data live?+

Your Git repositories stay on your machine. GitHub and AI features connect to the services you choose and may send data as needed for the requests you ask them to process.

Which version can I download?+

Choose User Setup (EXE) for your Windows account or Admin Setup (MSI) for all users. Both x64 and ARM64 are available below, alongside Linux AppImage, DEB and RPM packages and a macOS .dmg (universal). Windows installers are unsigned.
